# ToCS Workshop Repository

This repository contains all relevant materials for the workshop on the
ToCS (Toxicokinetic Chemical Simulator) graphical user interface (GUI).
There are four sessions of the workshop, and each with their PowerPoint
slide decks located under the ‘Slides’ folder. Any additional session
materials (csv, xlsx, zip, and R files) are located in the corresponding
folder.

## Getting Help

Questions regarding any of the materials should be submitted by clicking
the link
<https://github.com/KristenWindoloski/ToCS_WorkshopMaterials/issues> and
then pressing the green “New issue” button.
